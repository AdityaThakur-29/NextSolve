# NextSolves — Practical Workflow System (PWS)

> **"The Operating System for the Future Campus."**  
> *From Question Papers to Practical Exams — We Automate Everything.*

An end-to-end digital examination and practical workflow platform designed for colleges. PWS transforms traditional paper-based, manually managed examination processes into a 100% paperless, centralized, automated, and secure digital workflow.

---

## 🚀 Key Features

- **Instant Exam Automation**: Teachers upload question banks and launch exams within minutes.
- **Random Digital Question Distribution**: Automated, randomized digital question slips replicate traditional randomness in a paperless format.
- **Digital Practical Examination**: Students enter code directly into the system — zero handwriting on paper.
- **Automated MCQ Evaluation**: Instant automatic grading and score calculation upon submission.
- **Live Surveillance & Monitoring**: Supervise lab batches, track student heartbeats, and prevent unauthorized external tools.
- **Safe Exam Browser Integration**: Controlled kiosk environment preventing tab-switching and cheating.
- **Automated Attendance**: Students are marked present immediately upon login.
- **Side-by-Side Grading Console**: Evaluate student code and execution outputs side-by-side.
- **Institutional ROI & Cost Estimator**: Interactive calculator projecting paper and administrative savings.
- **Centralized Institutional Data**: Permanent, encrypted digital score records and instant Excel/PDF export.

## ⚡ Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation & Run

1. Navigate to the website directory:
   ```bash
   cd website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
cd website
npm run build
npm start
```
